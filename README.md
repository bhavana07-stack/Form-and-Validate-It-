# Job Application Form with Validation

## Project Overview

This project is a responsive Job Application Form designed using HTML, CSS, and JavaScript. It allows users to enter their personal information and validates the input before submission.

## Features

* Name, Email, Phone, and Message fields
* Client-side form validation using JavaScript
* Empty field validation
* Email format validation
* Phone number validation
* Responsive design for desktop and mobile devices
* Modern and colorful user interface
* Animated success messages

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

Job-Application-Form

├── index.html

├── style.css

└── script.js

## Validation Rules

* All fields are required.
* Email must follow a valid format.
* Phone number must contain at least 10 digits.
* Success message is displayed after successful validation.

## How to Run

1. Download or clone the project files.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Fill in the form and test the validation.
